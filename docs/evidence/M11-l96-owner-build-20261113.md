## Owner PC runs (2026-11-13)

Owner PC runs on l96 (2026-11-13, build 277DB5EB confirmed, RTX 5060, 3840x2160 120 Hz, 1080p Unlocked, night Arcade Midnight sprint in the hills, MAIN save, about 13-16 driving minutes per arm; read by the primary from MCLA_LOWLAT / MCLA_READBACK lines): (1) default (strict on): no flicker; 41.7 fps; strict wait 5.2 ms/frame. (2) reflex (strict on + Reflex): init ok on the first try (vendor 0x10DE, result=ok), all markers consistent (a few sim-per-swap mismatches only around loads), sleep ~0.01 ms/frame (strict already bounds the CP), spin ~27 ms/min; 42.3 fps; owner: MUCH better, smoother, input delay far less noticeable ("40 feels like 60+"). (3) reflex-nostrict (strict off + Reflex): 44.8 fps; Reflex sleep 9.3 ms/frame (p99 ~15.5, max 21.8), spin 2.7 s/min (4.5 % of a core); lead2_frames 210 in 14 minutes (11 minutes with any; without Reflex and strict it was hundreds per minute), fence_late_f2p 1014; owner: no flicker at all (one doubtful single frame, probably headlights sweeping a building edge in a corner); feels as good as reflex or better. (4) reflex-markers (markers only, no sleep, strict on): owner: feels like default again: "these 40 feel like FORTY and the frame-time fluctuations are annoying after that smoothness". So the Reflex improvement is not a placebo, markers alone do nothing, and the Reflex sleep alone kept the KI-074 night flicker away at +3 fps over the strict bound. Single runs; a long soak and a dawn check of reflex-nostrict are still needed before changing defaults. Also seen: the game changes its bright-pass values within a session (threshold 1.10 -> 0.79 and back, intensity 0.73 -> 0.28 and back, preset byte unchanged), lowest exactly when the owner pressed F10 for "more bloom" (13:10:17): dynamic weather, supporting KI-077 = game state. Census on PC (default run): 41 k submission-fence polls per frame costing 1.8 ms/frame; 54 % of draws change constants only; 75 % of constant writes rewrite the same value.
