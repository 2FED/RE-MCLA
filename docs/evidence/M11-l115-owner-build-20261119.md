# M11 l115 owner build (2026-11-19): the draw extent bound is a Windows default again (resolve-only KI-084 fix)

**Headline.**
- l115 = main `77c0082` (the l114 host plus docs) with a host-only diff. It sets the default of
  the rectangle draw-extent bound back to true. No SDK change: it is built against
  `private/l114-sdk-install` (`mcla/m11-l114` `389d3bd`, 0.20.0.21-dev.g389d3bd), and the three
  SDK DLLs are byte-identical to l114's.
- **Decision.** The owner decided on 2026-11-18 that the bound is a default. l112 turned it off
  only because of KI-084 (the minimap flicker). Owner l114 result: the arm pc/extent-new (bound on,
  SDK-default resolve-only deferred mode 1) ran for 10 minutes of races with no minimap flicker.
  46-907 deferred claims were completed per minute before resolves, and GPU time was at the l111
  level.
- Built and unit-tested only: not signed, not run, no physical PASS.
- Spark not used: deterministic source edits, builds and static checks; no bounded extraction or
  triage task suited it.
