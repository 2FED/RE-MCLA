# l99 owner-internal build: MCLA_HITCH, texture churn fix arm, Reflex without the guard (2026-11-13)

Owner-internal candidate l99, implemented, built and staged by an Opus subagent for the primary
agent. **It has been built and unit-tested only. It is not signed and has not run in the game, so
there is no physical PASS.** l99 builds against a NEW SDK, `private/l99-sdk-install` (SDK
`d3d7b6c` on `mcla/m11-l99`, see [l99 SDK](M11-l99-sdk-hitch-20261113.md)); all seven pins are
new. Basis: [l98 pc/auto soak analysis](M11-l98-pc-auto-soak-analysis-20261113.md) (owner
priority: hard frame drops on the PC) and the owner's request for arms WITHOUT the guard, purely
with Reflex, to check whether Reflex copes on its own.

Guardrails:
- Nothing was launched (no `mcla.exe`, no launcher). No save, profile, ticket, key or registry
  entry was written. The arm helpers were dry-run against a scratch `LocalAppData`; the real
  per-user override file was not touched (same SHA-256 before and after the dry run).
- No git write in the main repository; the SDK commit is local on `mcla/m11-l99` (not pushed).
- `private/tools/wait-for-idle-pc.ps1` ran before every build and test command (the owner had
  closed the game; every step started on IDLE).
- No l98 file was changed (the hand-made l98 `pc\dawn-reflex-nostrict` arm and helper stay as
  they are; l99 builds its own from `pc\reflex-nostrict`).
- **Spark was not used:** deterministic implementation, build and staging work, checked by
  tests.
