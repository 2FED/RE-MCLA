- 95 % of draws go to 4x MSAA targets (10.88 M of 11.49 M in minute 19). At 2x2 draw scale that is 16 samples per guest pixel.
- Ownership transfers cost 5.64 ms per frame (30 % of GPU time) and are constant across minutes: about 44 colour, 32 depth and 27 stencil transfers per frame; the stencil ones run 213 per-bit passes per frame (NVIDIA: no pixel-shader stencil reference).
- Resolves: about 60 per frame, 2.3 ms. Texture loads, uploads and read-back: about 3 ms.
- Only about 7.5 ms of the 18.5 ms is the scene itself; about 11 ms is copying between surfaces.
- Barriers: about 1600 shared-memory COPY_DEST transitions per frame.

Ranking from these numbers: (1) avoid ownership transfers (the game's clears drawn as MSAA rectangles; the stencil path alone is 3.2 ms); (2) single-tile rendering (halves per-tile transfers and resolves, removes KI-083, large CP saving reported by peers); (3) resolve path (dump + copy 2.3 ms); (4) MSAA 4x -> 1x for the scene (part of the 6-7 ms draw cost; the guest_msaa_off arm may not act if the game forces 4x by other renderer bytes: Run 4 will tell).
