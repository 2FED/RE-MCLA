## 6. What the owner runs decide

- Run 1 (verify): `cmp_diff_valid` must be 0 and no `MCLA_SHM_HOT_BAD` (a non-zero value stops the lever).
  `cmp_same_but_faulted` above 0 is expected (same-bytes rewrites; harmless by construction, SDK document
  section 5). The projected saving: `arms_skipped`, `faults_hot` (by thread), `cmp_same_invalid`; the cost:
  `cmp_ms`, `cmp_us_per`; the hot set: `hot_pages_avg`, `shadow_mb_peak`, `exits`, `refused`.
- Run 2 (on), Deck acceptance as in the M11 Deck design: CP at least -2 ms per frame (`MCLA_PERF_SPLIT`
  cp_busy against Run 1 / l119), the render thread (`MCLA_SPIN`, `MCLA_SHM faults_render`) down, nothing seen.
  PC: neutral or better (then a Wine-only default is the likely outcome).
