### The 2 KiB limit and the helpers

The l80 arm files are 2019 to 2023 bytes with LF line ends. The earlier helpers wrote the arm through `echo`, which adds a CR to every line. That would make these files 2090 to 2094 bytes, over the 2048-byte `kMaxBytes` limit. The game would then reject the whole file and apply nothing.

The l80 helpers therefore do not use `echo`:
- `l80-arm-default.cmd` and `l80-arm-blend.cmd` copy `private\l80-arms\pc\<arm>\mcla-dev-overrides.txt` with `copy /b` and verify the copy with `fc /b`.
- `l80-arm-clear.cmd` deletes the file, as before.

Dry run: all three helpers were run with `LocalAppData` pointed at a scratch folder. The real per-user folder was not touched.
- The default and blend copies were byte-identical to their arm files.
- Clear removed the file.
- In the agent's shell, `find` resolved to GNU find, so the "game running" test printed an error. On the owner's Windows shell the same line uses Windows `find`, as in every earlier helper.
