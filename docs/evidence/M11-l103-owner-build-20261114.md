# l103 owner-internal build: Reflex protection for the AMD Anti-Lag 2 path (2026-11-14)

Owner-internal candidate l103, implemented, built and staged by an Opus subagent for the primary
agent. **It has been built and unit-tested only. It is not signed and has not run in the game, so
there is no physical PASS.** l103 builds against the **unchanged** l101 SDK,
`private/l101-sdk-install` (SDK `a49e511` on `mcla/m11-l101`); the three SDK DLL pins equal the
l102 (= l101) pins (asserted by the staging script and by the prepare-script generator).
l103 = l102 + two dev-override keys (133 keys), both default off, plus six new `amd/` arms.
Basis: [l102 owner build](M11-l102-owner-build-20261114.md), gap and proposal in
[AMD iGPU Anti-Lag 2 readiness](M11-amd-igpu-antilag2-readiness-20261114.md) section c.

## 1. What changed vs l102

- `=false` writes nothing for both; no conflict pairs (different cvars from every other key).
- Both cvars are in `kNeverWrittenCvars` (102 -> 104): the m10 defaults never write them, so
  without an arm the SDK defaults (`false`) apply and nothing changes.
- An SDK without the two cvars logs them as unavailable (the usual rule).
- Existing keys unchanged: `lead_ll_off_when_reflex` still writes 1 to
  `d3d12_frame_lead_strict_low_latency` (its name says Reflex; with `lead_ll_count_antilag2` the
  same mode applies to Anti-Lag 2), `low_latency_auto` still writes `auto` to
  `d3d12_low_latency_mode`.
