## What is measured afterwards

- `MCLA_PERF_SPLIT`: cp_busy per frame, packets_other, draw phases (texture, render target, bindings), pkt_t0_ms; Run 1 against l96 (55.9 ms, 5890 draws) and Run 3. The Deck frame is quantised to 16.7 ms steps (p50 66.6 ms in l96), so CP savings show as fps only once frames fall under 50 ms: read cp_busy, not only fps.
- `MCLA_TEXMEMO`, `MCLA_CP_L101`, `MCLA_CP_L100`: memo v2 hits/misses, RT memo hits, regs_skipped / const_dw_skipped on the Deck.
- `MCLA_AFILT`: native filter engine frames/s (needed 187.5; l96 afnative 186.7) and REX_PERF_AUDIT underruns at F10s, against the owner's ear.
- Run 2: `MCLA_XFER_ELIDE` / `MCLA_XFER_EXTENT` lines with on=1, elided counts, deferred claims; cp_busy and GPU busy against Run 1.
- `MCLA_LOWLAT` must show backend=none result=wine; `MCLA m10 defaults` summary lines platform=wine with transfer elision / extent false in Runs 1 and 3.
- Build identity: each session's launch receipt against the build manifest hash above.
